# Synthetic legal document sample dataset

Eight original synthetic PDF documents and linked JSON/CSV fixtures. All parties and clauses are fictional examples. Do not use as signed contracts or legal advice.

Folders: contracts, ndas, vendor_agreements, leases, licenses, clauses, risk, expiry, rag, evaluation.

IDs match across PDF files, clauses, risk scores, expiry tracking and QA fixtures.

Run `python validate_sample.py` from this directory to validate the data and PDF files (requires pypdf).
